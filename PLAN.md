# 3D Printed Fingerboard Plan

**Printer:** Bambu Lab H2C (AMS, 40W laser)
**Nozzles:** 0.4 hardened (Vortek + left), 0.6 hardened (Vortek), 0.2 stainless
**Deck width:** 34mm
**Rule:** use only materials on hand (PLA/PLA+, PETG, TPU, PA-CF/PETG-CF/PC, 3mm walnut ply, 3mm birch ply, 3mm acrylic, 2mm cork)

---

## 1. Deck — multi-color PETG

- **Model:** [Print-in-Place Finger Board Pro (MakerWorld 3030564)](https://makerworld.com/en/models/3030564), ~96 x 34mm. Use the deck only, or import the deck shape and add your own graphic.
- **Material:** PETG for the whole deck, including the graphic colors. PETG doesn't bond to PA-CF or PLA, so don't mix them in one deck.
- **Graphic:** print the deck **upside down** so the graphic sits on the build-plate side. The textured PEI plate leaves a clean finish. Make the graphic 2–3 layers deep (0.4–0.6mm) and keep it in the bottom layers so color swaps stay cheap.
- **Nozzle:** 0.4 hardened. Use 0.2 stainless only for a tiny logo test.
- **Settings:** 0.12–0.16mm layers, 4 walls, 100% infill (or 40% gyroid plus 5 top/bottom layers), with brim off. Let the slicer prime-tower purge handle color changes.
- **Stiffer version (single color):** PA-CF with the 0.4 hardened nozzle. Dry it at 80°C for 8h first.
- **Grip:** model a shallow diamond or knurl texture on the top surface, about 0.3mm deep. Cork is too thick to use as grip tape.

## 2. Trucks

- **Option A (best):** reuse the Tech Deck trucks and their screws on the printed deck. Match the deck's hole pattern to the Tech Deck trucks.
- **Option B (printed):** [Magnetic Fingerboard (MyMiniFactory)](https://www.myminifactory.com/object/3d-print-magnetic-fingerboard-75119) or [Print-in-Place board (Printables 690876)](https://www.printables.com/model/690876-finger-board-skate-board-print-in-place).
  - **Hanger + baseplate:** PA-CF or PC, 0.4 hardened, 100% infill. The axles are the weak point, so print them along the hanger length, not vertically.
  - **Bushings:** TPU, printed at 30–50% infill to make them softer.
  - **Kingpin:** without any bolts, use a printed PA-CF pin and a friction cap. With bolts, the standard sizes are below.

### Bolt sizes (for reference)
| Use | Size |
|---|---|
| Truck mounting screws | M2 x 6mm (Tech Deck screws work) |
| Kingpin | M3 x 10–12mm + M3 nylock nut |
| Wheel axle nut (pro trucks) | M3 thread |

## 3. Wheels (no bearings)

- **Material:** PETG cores, 0.4 hardened, 100% infill. Ream the bore with a 3mm drill bit so it spins freely.
- **Multi-material option:** a PETG core with a TPU tire layer, printed in the same job on the H2C.
- **Settings:** print the wheels flat, at 0.12mm layers so they come out rounder.
- **Spare set:** keep the Tech Deck wheels for when the printed ones wear out.

## 4. Obstacles

| Obstacle | Model | Print | Laser / extras |

Check each model's license before sharing or selling prints.

## 5. Laser cut list (H2C 40W)

| Part | Material | Notes |
|---|---|---|
| Display stand / wall mount | 3mm walnut ply | Engrave your logo; slot the deck in at an angle |
| Ledge & box tops | 3mm acrylic | Cut slowly with air assist on |
| QP side panels | 3mm birch ply | Trace the outline from the QP model's side profile |
| Anti-slip pads | 2mm cork | Glue under every obstacle |

Run a test grid on a scrap piece of each material before the real cut.

## 6. Build order

1. Dry the PETG and do a 20mm color test of the deck graphic.
2. Print the deck, then mount the Tech Deck trucks and wheels to test it.
3. Print one set of PA-CF trucks and PETG wheels, and compare them with the Tech Deck parts.
4. Print the Euro Gap set, then laser-cut the cork pads.
5. Print the quarter pipe and laser-cut its birch sides, then make the acrylic ledge top and the walnut stand.

## Later upgrades (if you ever buy parts)

- 0.6mm maple veneer: laser-cut 5 plies and press them in a printed mold ([MOLD F.O.R.G.E. 34mm](https://makerworld.com/models/2542743)) for a real wood deck.
- Bearings for the wheels: 2x6x3mm, as used by the Magnetic Fingerboard model.
